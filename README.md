# MegaGuard Connect · πρόσθετο για Home Assistant

Συνδέει ένα σπίτι (Home Assistant) με το κέντρο λήψης σημάτων της Mega Guard.
Μόνο εξερχόμενη σύνδεση HTTPS προς τον server· καμία ανοιχτή πόρτα στο σπίτι.

## Εγκατάσταση
1. Home Assistant → Ρυθμίσεις → Πρόσθετα → Κατάστημα προσθέτων → ⋮ → Αποθετήρια → προσθήκη:
   `https://github.com/sakisdrakidis-cmd/megaconnect-ha`
2. «MegaGuard Connect» → Εγκατάσταση.
3. Ρυθμίσεις του προσθέτου → `home_key`: το κλειδί από την κονσόλα (Σπίτια → Νέο σπίτι) → Αποθήκευση → Εκκίνηση.
4. Στο «Αρχείο καταγραφής» πρέπει να δείτε «Συνδέθηκε · N αισθητήρες».
